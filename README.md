# Network Engineering Portfolio

Welcome to my Network Engineering Portfolio.

This repository showcases independently designed, implemented, configured, and documented network infrastructure projects using Cisco Packet Tracer.

The projects demonstrate practical knowledge of enterprise networking, LAN infrastructure, routing and switching, network security, network services, and troubleshooting.

I am an aspiring Network Engineer with practical experience designing, configuring, implementing, and troubleshooting network infrastructures through independent networking projects.

I use this portfolio to demonstrate my understanding of networking technologies through practical implementations and technical documentation.
